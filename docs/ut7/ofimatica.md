# Ofimática y documentación técnica

Las herramientas ofimáticas permiten crear documentos, hojas de cálculo y presentaciones para documentar procedimientos.

## Herramientas habituales

| Herramienta | Uso | Opción libre |
| ----------- | --- | ------------ |
| Procesador de textos | Memorias, manuales | LibreOffice Writer |
| Hoja de cálculo | Inventarios, presupuestos | LibreOffice Calc |
| Presentaciones | Exposiciones | LibreOffice Impress |
| Markdown | Documentación técnica ligera | VS Code |

## Ejemplo de documento en Markdown

```markdown
# Título del procedimiento

1. Primer paso
2. Segundo paso

| Columna A | Columna B |
| --------- | --------- |
| Dato 1    | Dato 2    |
```

> [!NOTE]
> Markdown es ideal para documentación técnica porque es texto plano, se versiona con Git y se convierte fácilmente a HTML o PDF.

> [!TIP]
> Incluye capturas de pantalla pertinentes y explica cada paso con claridad.
